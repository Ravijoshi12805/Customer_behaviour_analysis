# Customer_behaviour_analysis
data analytics project showcasing customer behavior analysis using python, sql and power bi.

📊 Data Analytics Project — End-to-End Data Analysis & Business Intelligence
Overview

This project demonstrates an end-to-end data analytics workflow, starting from dataset loading and data cleaning in Python to SQL analysis, Power BI dashboard creation, reporting, and presentation.

The project focuses on transforming raw data into meaningful business insights using Python, PostgreSQL/MySQL/SQL Server, Power BI, and presentation tools.

📁 Dataset
The project uses a structured dataset containing business/e-commerce-related records.
The dataset was processed to:
- Understand the structure and columns
- Identify missing values
- Detect duplicate records
- Check data types
- Identify potential outliers
- Clean and prepare the data for analysis
- Extract useful business insights
 
🛠️ Tools & Technologies
Tool	Purpose

Matplotlib	Data visualization

PostgreSQL / MySQL / SQL Server	Database management and SQL analysis

🔄 Project Workflow
1. Load Dataset
The dataset was loaded into Python using Pandas.
import pandas as pddf = pd.read_csv("dataset.csv")

2. Data Cleaning
The raw dataset was examined and cleaned by:
- Handling missing values
- Removing duplicate records
- Correcting data types
- Removing unnecessary columns
- Checking inconsistent values
- Identifying potential outliers
  
3. Exploratory Data Analysis (EDA)
EDA was performed to understand patterns and relationships in the dataset.
Key activities included:
- Descriptive statistics
- Frequency analysis
- Category-wise analysis
- Trend analysis
- Distribution analysis
- Visualization of important variables
  
4. SQL Analysis
The cleaned dataset was imported into a relational database and analyzed using SQL.
Examples of analysis included:
- Aggregations using SUM(), AVG(), COUNT()
- GROUP BY analysis
- Filtering using WHERE
- Sorting using ORDER BY
- Joining tables using JOIN
- Business-oriented analytical queries

5. Power BI Dashboard
The analyzed data was connected to Power BI to create an interactive dashboard.
The dashboard includes:
- KPIs
- Charts and graphs
- Category analysis
- Trend analysis
- Filters and slicers
- Business performance insights
  
6. Report & Presentation
The findings were summarized in a professional report and presentation created using Gamma.
The presentation highlights:
- Project objective
- Data preparation
- Analysis methodology
- Key findings
- Dashboard
- Business insights
- Final conclusions
  
📊 Dashboard
The Power BI dashboard provides an interactive view of the most important metrics and trends.
Key features:

- Comparative visualizations
- Business insights

📈 Key Results
The analysis helped identify:
- Important performance trends
